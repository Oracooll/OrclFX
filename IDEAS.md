# Ideas for later

Suggestions that were proposed but not chosen (yet). Kept here for later review; nothing on this list is
planned. When one gets built, move it to the CHANGELOG and delete it here.

## Proposed 2026-10-06, round 1
- **Copy and move to the other pane (F5 / F6)**: the selected files go to the folder open in the next pane,
  with Windows' own copy dialog, conflict prompts and undo.
- **Filter as you type**: a box that narrows the current folder's list to names containing the text
  (`*.pdf`, `invoice`); cleared when you leave the folder.
- **Mouse back / forward buttons**: the side buttons of a mouse go back and forward in the tab under the pointer
  (the app doesn't handle them itself).
- **Recent folders and jump to folder**: a drop-down on Back / Forward, and a "go to" box (Ctrl+G) that fuzzy-matches
  recently visited folders.
- **Compare panes**: mark the files that differ between the two panes (missing on one side, newer, different size).
- **Synchronised browsing**: a toggle that makes the other pane follow into the same subfolder.
- **Batch rename**: rename the selection with a pattern (`Holiday ###`), find/replace or a date prefix, with a
  preview before anything changes.
- **Copy path of the selected files**: one key copies the full paths of the selected items. (Clicking the address bar
  already copies the folder's own path, since 1.1.027.)
- **File checksum**: show a file's SHA-256 from the right-click menu, to verify downloads.

## Proposed 2026-10-06, round 2
- **Drag a tab to another pane** (tabs can only be reordered within their pane).
- **Reopen closed tab** (Ctrl+Shift+T), as in browsers.
- **Swap panes** (Ctrl+U): exchange the tabs of the two panes.
- **Duplicate finder**: find identical files under a folder by size and content, shown in a results tab like Find.

## Proposed 2026-10-06, round 3
- **Tabs from your other PC**: each PC saves a snapshot of its open tabs next to the shared shortcuts, and the
  Layouts menu offers "Tabs on LAPTOP" on the other machines.
- **Files in the Shortcuts pane**, not only folders (double-click opens the file).
- **Home folder per pane** (Alt+Home), set from the tab menu.
- **Copy a file list**: the selection or the whole folder as a table (name, size, date, path) to paste into Excel
  or an email.
- **Unblock downloaded files**: remove Windows' "downloaded from the internet" mark from the selection in one go
  (stops "Are you sure you want to open this file?" and Office's Protected View for files you trust).
- **Git status for code folders**: the branch and the number of changed files in the status bar for a git
  repository folder.

## Proposed 2026-10-06, Space Viewer (ideas from FastStone Image Viewer)
- **Animated GIFs play** in the viewer instead of showing their first frame.
- **Slideshow** (S) through the folder with a set interval; any key stops it.
- **Compare**: 2-4 selected pictures side by side, zooming and panning together.
- **Open in editor** (E) with the default picture editor, and **Set as wallpaper**.
- Left out as too heavy for a quick viewer: crop / resize / colour and red-eye editing, drawing, batch convert or
  rename, histogram, magnifier lens, printing, e-mail.
